# DFWhacks - Dallas-Fort Worth Hackathon Website

A The website for the DFWhacks hackathon event that took place on September 25 2025 at Collin County Community College. Built with HTML, CSS (Tailwind), and JavaScript.

## Sections

1. **About**: Information about the hackathon and what to expect
2. **Schedule**: Detailed 3-day event timeline
3. **Prizes**: Prize breakdown and special categories
4. **Sponsors**: Sponsor showcase and sponsorship opportunities
5. **Registration**: Link to Registration Form

## Customization Guide

### Colors
- Primary: `purple-600`, `purple-700`
- Secondary: `gray-50`, `gray-100`
- Gradients: `.gradient-bg` and `.hero-gradient` in the `<style>` section
